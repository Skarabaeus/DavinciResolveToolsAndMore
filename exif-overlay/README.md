# EXIF Overlay for DaVinci Resolve

An animated Fusion Title template for DaVinci Resolve that shows a photo's camera settings as an overlay: camera, lens, focal length, ISO, shutter speed and aperture. Each value gets an icon, and the rows reveal one after another.

Tested with DaVinci Resolve Studio 21.1.1 on macOS.

## What it looks like

- Six rows stacked in the bottom-left corner, top to bottom: **Camera, Lens, Focal length, ISO, Shutter, Aperture**.
- Each row has a line icon (amber by default) and the value in white Open Sans. The camera name is bold and the lens is semibold.
- There is no background card. A soft drop shadow keeps the text readable on bright photos.
- **Intro:** rows appear top to bottom with a short stagger. Each icon pops in with a slight overshoot and a small turn, while its text fades in and slides in from the left.
- **Outro:** at the end of the clip, rows fade out in reverse order (bottom to top).

The timing is in seconds and follows the length of the title clip. It looks the same at any frame rate and any title duration, and you change the length by trimming the clip on the timeline.

## Files

| File | Purpose |
|---|---|
| `EXIF Overlay.setting` | The title template that Resolve loads. Generated by `build_template.py`. |
| `icons/` | The six icon images (white, 256×256, transparent background). |
| `build_template.py` | Generates `EXIF Overlay.setting`. Layout, sizes, fonts and default colors are constants at the top of the file. |
| `render_icons.js` | Renders the icon images from the [Lucide](https://lucide.dev) icon set (`lucide-static`). |

## Installation

1. Find Resolve's user templates folder:
   - **macOS:** `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Templates/Edit/Titles/`
   - **Windows:** `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Titles\`
   - **Linux:** `~/.local/share/DaVinciResolve/Fusion/Templates/Edit/Titles/`
2. Copy `EXIF Overlay.setting` directly into that `Titles` folder.
3. Create a folder named `EXIF Overlay Icons` next to it and copy the six images from `icons/` into it.

The result should look like this:

```
Fusion/Templates/Edit/Titles/
├── EXIF Overlay.setting
└── EXIF Overlay Icons/
    ├── aperture.png
    ├── camera.png
    ├── focal.png
    ├── iso.png
    ├── lens.png
    └── shutter.png
```

On macOS you can do this from the `exif-overlay` folder with:

```bash
T="$HOME/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Templates/Edit/Titles"; mkdir -p "$T/EXIF Overlay Icons" && cp "EXIF Overlay.setting" "$T/" && cp icons/*.png "$T/EXIF Overlay Icons/"
```

Resolve picks up new templates by itself after a few seconds. If it doesn't show up, restart Resolve.

> **Important:** don't put the `.setting` file in a subfolder with the same name, such as `Titles/EXIF Overlay/EXIF Overlay.setting`. Resolve still lists the title, but it loads as an empty composition and shows a black screen.

The icon folder name is fixed: the template looks for the images at `Templates:Edit/Titles/EXIF Overlay Icons/`. If you want them somewhere else, change `ICON_DIR` in `build_template.py` and rebuild.

## Usage

1. On the Edit page, open **Effects → Titles** and drag **EXIF Overlay** onto a video track above your photo.
2. Trim the title to the length you want. The intro and outro adjust automatically.
3. Select the title and set the values in the **Inspector**.

### Inspector controls

| Control | Default | Description |
|---|---|---|
| Camera, Lens, Focal, ISO, Shutter, Aperture | sample values | The text for each row. |
| Position | 0.5 / 0.5 | Moves the whole block. |
| Scale | 1 | Scales the whole block from its bottom-left corner. |
| Text Color | white | Color of all values. |
| Icon Color | amber `#FFC857` | Color of all icons. |
| Icon Size | 1 | Icon size relative to the text. |
| Stagger (s) | 0.12 | Delay between rows during the reveal. |
| Reveal Duration (s) | 0.55 | How long each row takes to animate in. The outro is a bit faster. |
| Start Delay (s) | 0 | Seconds after the clip starts before the intro begins. |
| Visible For (s) | 0 | Seconds from the start of the intro until the outro ends. 0 means until the end of the clip. |
| Shadow Strength | 0.75 | Opacity of the drop shadow. |
| Shadow Softness | 4 | Blur of the drop shadow. |

The values are typed by hand here. The [Add Photos](../photo-frame/) script fills them in automatically from each photo's EXIF data.

## How it works

The template is a Fusion macro (`MacroOperator`) with all controls published to the Inspector. Inside it:

```
Controls (transparent Background, holds the custom controls)
  └─► for each row:
        Merge  ◄── Text+ (value)
        Merge  ◄── ColorGain (tint) ◄── Loader (icon image)
  └─► Layout (Transform: Position / Scale)
  └─► DropShadow (Merge of the overlay over a blurred, darkened copy)
  └─► output
```

- **Controls:** a fully transparent Background node is the base of the image chain. It also holds the custom inputs (colors, stagger, duration, icon size). All other nodes reference them through expressions such as `Controls.TextRed`.
- **Text:** one Text+ per row, left-aligned, with its color linked to the Text Color control.
- **Icons:** each icon image is loaded with a Loader and tinted with a ColorGain node linked to the Icon Color control. The Loaders are set to hold their single frame for the whole clip, so the icon appears on every frame. The icon size is multiplied by `frame width / 1920`, so icons keep the same size relative to the text at 1080p, 4K or any other resolution.
- **Animation:** there are no keyframes. Each row's Merge nodes use Lua expressions that work out the animation progress from the current frame:
  - `t = (time - comp.GlobalStart) / fps - Start Delay` is the time since the overlay started, in seconds.
  - Intro progress for row *i* starts at `0.1 + i × Stagger` and runs for `Reveal Duration`, eased with an ease-out cubic curve.
  - Outro progress counts back from `Start Delay + Visible For` (or from `comp.GlobalEnd` when Visible For is 0) with the row order reversed.
  - Text slides in with an offset on its Merge's `Center`. The icon uses a back-ease (overshoot) on the Merge's `Size` plus a small rotation.
  - The intro and outro values are multiplied together to drive each Merge's `Blend` (opacity).
  - The clip's global range is used instead of the render range on purpose, because the render range changes when Resolve renders single frames.
- **Shadow:** the finished overlay is blurred (Blur), turned black at reduced opacity (ColorGain), and placed under the sharp overlay with a small offset. Resolve's built-in Shadow tool was tried first and drew nothing.

## Rebuilding

### Template

After changing `build_template.py`, regenerate the template and install it again (see [Installation](#installation)):

```bash
python3 build_template.py "EXIF Overlay.setting"
```

The main settings at the top of `build_template.py` are:

- `ROWS`: each row's name, icon, default text, text size and font style.
- `X_ICON`, `X_TEXT`, `Y_BOTTOM`, `SPACING`: where the rows sit, in normalized frame coordinates (0 to 1).
- `ICON_SCALE`: the icon's base size (256 px × 0.15 ≈ 38 px on a 1920-wide frame).
- `ICON_DIR`: where the template looks for the icon images.

### Icons

The icons come from [`lucide-static`](https://www.npmjs.com/package/lucide-static) version 1.55.0 and are rendered to PNG with [`sharp`](https://www.npmjs.com/package/sharp):

| Row | Lucide icon |
|---|---|
| Camera | `camera` |
| Lens | `focus` |
| Focal length | `ruler-dimension-line` |
| ISO | `gauge` |
| Shutter | `timer` |
| Aperture | `aperture` |

To render them again (for example after picking different icons in the `map` inside `render_icons.js`), install the two packages in a separate folder and point the script at it:

```bash
mkdir -p ~/tmp/lucide-deps && npm install --prefix ~/tmp/lucide-deps lucide-static sharp
```

```bash
node render_icons.js ~/tmp/lucide-deps icons
```
