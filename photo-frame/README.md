# Photo Frame for DaVinci Resolve

Two tools for showing photos in a video:

- **Photo Frame** is a Fusion Effect template. Drop it on a photo clip and it scales the photo down, adds a white border with a soft drop shadow, and puts a four-corner gray gradient behind it. The result is a full 16:9 frame.
- **Add Photos** is a script. It puts the photos selected in the Media Pool on the timeline at the playhead, one after another. Each photo gets the Photo Frame look, an [EXIF Overlay](../exif-overlay/) filled in from the photo's metadata, and a camera shutter sound.

Tested with DaVinci Resolve Studio 21.1.1 on macOS.

## Files

| File | Purpose |
|---|---|
| `Photo Frame.setting` | The effect template that Resolve loads. Generated by `build_template.py`. |
| `build_template.py` | Generates `Photo Frame.setting`. Default size, border, gradient colors and shadow are constants at the top. |
| `Add Photos.py` | The script. Its settings are at the top of the file. |

## Installation

Add Photos also needs the [EXIF Overlay](../exif-overlay/) title installed, including its icons. Install it first.

From the `photo-frame` folder:

```bash
R="$HOME/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion"; mkdir -p "$R/Templates/Edit/Effects" "$R/Scripts/Edit" && cp "Photo Frame.setting" "$R/Templates/Edit/Effects/" && cp "Add Photos.py" "$R/Scripts/Edit/"
```

Resolve picks up the template after a few seconds. The script shows up in the **Workspace → Scripts** menu on the Edit page. If either one is missing, restart Resolve.

## Usage

### Add Photos (script)

1. In the Media Pool, select one or more photos.
2. On the timeline, put the playhead where the first photo should start.
3. Run **Workspace → Scripts → Add Photos**.

For each photo, in file-name order, the script:

- puts the photo on **V2**, with the Photo Frame look and the EXIF Overlay in the clip's Fusion composition
- fills in the overlay from the photo's EXIF data, which Resolve already reads on import: camera, lens, focal length, ISO, shutter speed and aperture
- puts the camera sound on **A1** at the start of the photo
- starts the next photo where this one ends

Afterwards the playhead sits after the last photo, so running the script again carries on from there.

The script never overwrites anything. If V2 isn't free at the playhead, it stops and tells you how many photos it added.

**Photo duration** comes from Resolve's *Standard still duration* preference (**Preferences → User → Editing**). The scripting API can't set it. The overlay timing is in seconds, so it doesn't depend on the photo's length.

#### Script settings

These are at the top of `Add Photos.py`. Re-copy the script after changing them.

| Setting | Default | Description |
|---|---|---|
| `VIDEO_TRACK`, `AUDIO_TRACK` | 2, 1 | Target tracks. Missing tracks are created. |
| `SOUND_FILE` | camera sound path | Sound placed at the start of each photo. It is imported into the Media Pool if it isn't there yet. Set to `""` for no sound. |
| `OVERLAY_DELAY` | 1.8 | Seconds from the photo's start until the overlay starts. |
| `OVERLAY_SECONDS` | 5.0 | How long the overlay stays. 0 keeps it until the photo ends. |
| `ICON_COLOR`, `TEXT_COLOR` | green, white | Overlay colors (R, G, B from 0 to 1). |
| `CAMERA_NAMES` | a few Sony models | Replaces EXIF model codes with readable names, for example `ILCE-7M4` → `Sony A7 IV`. |
| `BRANDS` | common makers | How maker names are written. `NIKON Z 8` becomes `Nikon Z 8`. |

#### Changing a photo afterwards

Everything for a photo lives in that clip's Fusion composition, so moving or trimming the clip takes the frame and overlay with it. To fix a value, select the clip, open the **Fusion** page and edit the `TextCamera`, `TextLens`, etc. nodes. The frame controls are on the `Frame` node, and the overlay controls are on the `Controls` node.

### Photo Frame (effect only)

On the Edit page, open **Effects → Effects** and drag **Photo Frame** onto a photo clip. Leave the clip's Zoom at 1.0, because the effect does the scaling itself. Then add the EXIF Overlay title and the sound by hand if you want them.

| Control | Default | Description |
|---|---|---|
| Photo Size | 0.9 | Size of the photo (without border) relative to the frame. |
| Border Width | 0.013 | Border width relative to the frame height (about 28 px at 2160). |
| Border Color | white | |
| Gradient Top Left / Top Right / Bottom Left / Bottom Right | grays | The four corner colors of the background. |
| Shadow Strength | 0.85 | Opacity of the drop shadow. |
| Shadow Softness | 30 | Blur of the shadow, in pixels at 1080p. |
| Shadow Distance | 0.005 | How far the shadow drops down, relative to the frame height. |
| Canvas Width / Height | 3840 × 2160 | Output size. Resolve fits it into the timeline, so only the aspect ratio has to match. The script sets it to the timeline resolution. |

## How it works

### Photo Frame

```
Frame (Background, four-corner gradient; holds the custom controls)
  └─► MergeShadow ◄── ColorGain (black) ◄── Blur ◄── CardLayer (Card on a transparent canvas)
  └─► MergeCard   ◄── Card (solid Background: photo size + 2 × border)
  └─► MergePhoto  ◄── PhotoIn (the clip)
  └─► output
```

- A Fusion composition on a clip runs at the clip's own resolution (5504 × 8256 for a portrait photo), and Resolve fits whatever comes out of it into the timeline. The effect therefore makes its own 16:9 canvas instead of using the composition's frame format.
- Merge places its foreground 1:1 in pixels, so the photo's Merge `Size` is the fit factor: `Photo Size × min(canvas width / photo width, canvas height / photo height)`. The downscale uses Lanczos filtering.
- The border card is a Background node whose width and height are expressions: photo size after scaling + 2 × border.
- The shadow is the card on a full-size transparent canvas (so the blur isn't clipped at the card's edges), blurred, turned black, and merged under the card with a small downward offset.

### Add Photos

- The scripting API can't add an effect to a clip, and `InsertFusionTitleIntoTimeline` always inserts (rippling the timeline) on the destination track, which scripts can't choose. The script therefore builds one Fusion composition per photo: `MediaIn → Photo Frame → Merge with EXIF Overlay → MediaOut`. It loads the composition with `TimelineItem.ImportFusionComp`.
- The composition is assembled from the two installed `.setting` files, so updating either template also updates future script runs. The overlay's canvas size is set to the timeline resolution, because the clip composition runs at the photo's resolution.
- EXIF values come from the Media Pool clip properties (`Camera Type`, `Lens Type`, `Focal Point (mm)`, `ISO`, `Shutter Speed`, `Camera Aperture`).
- The overlay timing uses the EXIF Overlay's *Start Delay* and *Visible For* controls.
- `AppendToTimeline` never overwrites. If the target spot is taken, it moves or shortens the new clip instead, so the script checks where each clip landed and removes it if it isn't exactly at the playhead.

## Rebuilding

After changing `build_template.py`, regenerate the template and install it again:

```bash
python3 build_template.py "Photo Frame.setting"
```
